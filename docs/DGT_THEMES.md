# DiveGram: документация по темам `.dgt`

Тема `.dgt` — обычный текстовый файл в стиле CSS, который перекрашивает и перестраивает
интерфейс DiveGram (форк Telegram). Тема применяется ко всему дереву интерфейса — экранам,
спискам, шторкам и оверлеям — и умеет менять цвета, фоны, скругления, тени, шрифты,
размеры, позиции, а также **обрезать любые элементы по фигуре** (круг, звезда, «печенье»,
произвольный SVG-контур и т.д.).

Механизмов, зашитых в приложение, минимум: почти всё задаётся самим файлом темы.

---

## 1. Как установить тему

Любой из способов:

1. **Экран «Темы»** (Настройки → DiveGram → Функции → «Темы») → импорт файла из хранилища.
2. **Клик по файлу `.dgt`** в файловом менеджере (запустится приложе­ние — есть intent-фильтр).
3. **Клик по файлу `.dgt` в чате** — если это документ, тап по превью установит тему.

После установки файл появляется в списке тем; тумблер справа включает тему.
Активной может быть только одна тема. Чтобы установка работала, режим
**«Оптимизация»** (для слабых устройств) должен быть выключен — при нём темы
блокируются с сообщением «Выключите „Оптимизацию“…».

## 2. Структура файла

```
__name__ Neon
__author__ Nick
__version__ 1.2
__icon__ ic_divegram

.avatar { ... }
#chatBackground { ... }
```

| Метаданные   | Значение                                        | Обязателен |
|--------------|--------------------------------------------------|-----------:|
| `__name__`   | Название темы в списке                            | нет        |
| `__author__` | Автор                                           | нет        |
| `__version__`| Версия (строка)                                  | нет        |
| `__icon__`   | Имя drawable из APK для иконки темы (опционально) | нет        |

Комментарии: `/* ... */` (многострочные) и `// ...` (однострочные).
Файл должен содержать хотя бы одно непустое правило — иначе он недействителен.

## 3. Селекторы

Правило применяется, если **хотя бы один** селектор в списке (через запятую) совпал.

| Селектор      | Что выбирает                                                            |
|---------------|--------------------------------------------------------------------------|
| `*`           | Любой элемент интерфейса                                                  |
| `.класс`      | Токен класса: алиас (см. таблицу ниже) **либо** имя Java-класса без пакета |
| `#имя`        | Гранулярный хук: android:id ресурса (например `#backButton`)             |
| `Тип`         | Простое имя Java-класса, например `TextView`                             |

Дочерние селекторы CSS (`A B .class`) не поддерживаются — берётся последний токен.
Не смешивайте `.` и `#` в одном селекторе — правило игнорируется.

### 3.1 Алиасы классов

| Алиас        | Java-класс                          | Описание                        |
|--------------|--------------------------------------|---------------------------------|
| `image`      | `BackupImageView`                    | Любая картинка                  |
| `avatar`     | `SimpleAvatarView`, `AvatarsImageView`, `ChatAvatarContainer`, `AnimatedAvatarContainer` | Аватарки |
| `list`       | `RecyclerListView`, `BlurredRecyclerView` | Списки                    |
| `action-bar` | `ActionBar`                          | Верхняя панель                  |
| `button`     | `ActionBarMenuItem`                  | Кнопки тулбара                  |
| `search`     | `FragmentSearchField`                | Поиск                           |
| `enter`      | `ChatActivityEnterView`              | Поле ввода сообщения            |
| `dialog-cell`, `chat-cell`, `cell` | `DialogCell`   | Ячейка списка чатов             |
| `message`    | `ChatMessageCell`                    | Сообщение в чате                |
| `user-cell`  | `UserCell`                           | Ячейка с пользователем          |
| `cell`       | `TextCell`, `TextCheckCell`, `CheckBoxCell` | Настраиваемые ячейки      |
| `text`       | `SimpleTextView`, `TextView`         | Текст                           |

Кроме алиасов работает **имя любого класса**: `.Linearlayout`, `.TextView`,
`.Dialogcell`, `.Imageview` и т.п. (регистр не важен).

### 3.2 Гранулярные селекторы картинок (формы аватарок и медиа)

Для изображений фигура задаётся отдельными селекторами (обрабатываются на уровне
отрисовки, точнее чем общая форма view):

| Селектор           | Где работает                            |
|--------------------|------------------------------------------|
| `.avatar`          | Все реальные аватарки                    |
| `.avatar-chat-list`| Аватарки в списке чатов                  |
| `.avatar-chat`     | Аватарки в сообщениях чата               |
| `.avatar-profile`  | Большая аватарка профиля                 |
| `.avatar-header`   | Аватарка в шапке чата                    |
| `.sticker`         | Анимированные (tgs/lottie) стикеры       |
| `.gif`             | GIF (анимированные файлы)                |
| `.round-video`     | Кружочки (круглые видео)                 |
| `.image`           | Любые картинки через `BackupImageView`   |

Эмодзи-спаны внутри текста и **статические** (webp) стикеры фигурой не обрезаются.

### 3.3 Контекстные селекторы экранов

Каждый фрагмент автоматически получает класс `frag-<ИмяЭкрана>`:
`frag-profileactivity`, `frag-settingsactivity`, `frag-chatactivity` и т.д.
Комбинировать нельзя — правило применяется ко всему элементу на этом экране.

```css
/* пример: скрыть кнопку поиска на экране настроек нельзя комбинацией,
   но можно перекрасить весь экран целиком */
.frag-profileactivity { background: #101820; }
```

## 4. Свойства

### 4.1 Форма и обрезка

```
shape: <значение>;        /* синонимы: clip-path, mask, shape-outside */
```

**Готовые фигуры** (все масштабируются под размер элемента):

| Значение             | Фигура                                            |
|----------------------|---------------------------------------------------|
| `none`               | Отменить обрезку                                  |
| `circle`             | Круг (вписан в меньшую сторону)                   |
| `circle(50%)`        | Круг радиусом 50% от меньшей стороны              |
| `ellipse`            | Овал на весь элемент                              |
| `ellipse(40% 60%)`   | Овал с полуосями 40%/60%                          |
| `square` / `rect`    | Прямоугольник (вписанный/полный)                  |
| `rounded(12px)`      | Прямоугольник со скруглением                       |
| `ring` / `ring(30%)` | Кольцо (аргумент — внутренний радиус)             |
| `heart`              | Сердце                                             |
| `sun(8)`             | Солнце (круг + лучи)                               |
| `star(5)`            | Звезда (3..N точек)                                |
| `burst(12)`          | Balanced звезда с глубокими лучами                 |
| `flower(6)`          | Цветок-розетка                                     |
| `triangle` `diamond` `pentagon` `hexagon` `octagon` | Правильные многоугольники |
| `cross` / `plus`     | Крест                                              |
| `drop` `leaf` `crescent` | Капля, лист, месяц                             |
| `blob`               | Скруглённый прямоугольник                          |
| `cookie(7)`          | «Печенье» Material Design 3: круг с N буграми      |
| `clover(4)`          |«Клевер» — печенье с глубокими буграми              |
| `puffy(8)`           | Пухлое печенье                                     |

**Универсальные формы** — полностью определяются в файле темы:

```
clip-path: polygon(50% 0%, 100% 38%, 82% 100%, 18% 100%, 0% 38%);
clip-path: circle(45%);
clip-path: ellipse(45% 55%);
clip-path: inset(10% 5% 10% 5%);
/* произвольный SVG-контур; координаты в системе 100x100,
   автоматически масштабируются под любой размер элемента */
clip-path: path("M 50 5 C 65 5 80 20 80 35 ... Z");
```

Команды SVG-контура: `M m L l H h V v C c S s Q q T t Z z` (поддерживаются
относительные и абсолютные формы; дуги `A` пока не поддерживаются).

### 4.2 Цвета и фон

```
background: #FF5500;
background-color: rgba(255, 85, 0, 0.8);
background: linear-gradient(180deg, #101820, #000000);
background: none;
border-radius: 14px;           /* синонимы: radius */
border-color: #00FF00;         /* синонимы: stroke */
border-width: 2px;
border-top-left-radius: 8px;   /* по углам */
border-top-color: #FFF;        /* по сторонам */
tint: #FFFFFF;                 /* перекраска иконок (ImageView и составные иконки текста) */
```

Цвета: `#RRGGBB`, `#AARRGGBB`, `#RGB`, `rgb(r g b [a])`, ключевые слова
(`black`, `white`, `red`, `orange`, `purple`, `transparent`, …).

Градиент: `linear-gradient( <наңr°>, <цвет1>, <цвет2> )` — 2 цвета, 4 направления.

### 4.3 Текст

```
color: #FFFFFF;            /* синонимы: text-color */
font-size: 16sp;
font-family: bold;         /* bold | medium — два шрифта Telegram */
line-height: 20px;
letter-spacing: 1px;
text-align: center;        /* text-align: left | right | center */
text-decoration: underline; /* underline | line-through */
text-transform: uppercase; /* uppercase | lowercase | capitalize */
text-shadow: 2px 2px 4px #000000;
text-overflow: ellipsis;   /* ellipsis | nowrap */
content: Привет_мир;       /* замена текста (подчёркивания = пробелы) */
```

### 4.4 Размеры, позиции и раскладка

Единицы: `px`, `dp`, `sp`, `%` (от ширины родителя), безсуффиксное число = dp.
Спецзначения для width/height: `match_parent`, `wrap_content`.

```
width: 200px; height: 48px; size: 56px;
min-width: 40px; max-height: 200px;
margin: 8px; margin-top / -bottom / -left / -right;
padding: 8px; padding-top / -bottom / -left / -right;
position: absolute;        /* для FrameLayout-родителя */
top: 0; left: 0; right: 0; bottom: 0;
aspect-ratio: 16 / 9;
display: none;             /* скрыть элемент */
visibility: hidden;         /* visible | hidden | invisible */
opacity: 0.8;
elevation: 4px;
```

### 4.5 Трансформации и фильтры

```
transform: rotate(15deg) scale(1.2);
translate-x: 4px; translate-y: 2px;
rotate: 45deg;
scale: 1.5; scale-x: 2; scale-y: 2;
filter: brightness(1.1) contrast(1.2) saturate(1.5) hue-rotate(30deg);
blur: 8px;               /* работает только на Android 12+ */
box-shadow: 4px 4px 8px #40000000;
```

### 4.6 Прочее

```
overflow: hidden;
clip: none;                /* отключает обрезку детей у родителя */
z-index: 100;
order: 2;                  /* перемещение ячейки в LinearLayout-списке */
outline: 2px #FFFFFF;      /* или outline-width / outline-color */
```

## 5. Полный пример

```
__name__ Neon_net
__author__ пример
__version__ 1.0

/* фон всего */
#chatBackground { background: linear-gradient(180deg, #0b0f1a, #000000); }
.frag-chatactivity { background: #0b0f1a; }

/* тулбар и поля */
.action-bar { background: #101828; }
#actionBarTitle { color: #7ee7ff; }

/* списки и ячейки */
.chat-list { background: #0b0f1a; }
.dialog-cell { background: #141b2b; border-radius: 12px; margin: 4px 8px; }
.message { color: #d7e4ff; }

/* аватарки */
.avatar-profile { clip-path: path("M 90 50 C 103.2 65.7 95.5 81.8 74.9 81.3 ... Z"); }
.avatar { shape: circle; }
```

## 6. Ограничения

- Нет анимаций и «transition» — тема применяется мгновенно.
- Не поддерживаются: дочерние селекторы (`A > B`, `A B`), псевдоклассы (`:hover` и т.п.),
  `@media`, `!important` (не обрабатывается специально, но последнее правило в файле выигрывает).
- Системные диалоги в отдельных окнах Android (не Telegram-шторки) не перекрашиваются.
- Статические (webp) стикеры и эмодзи-спаны в тексте не обрезаются фигурой.
- `blur` требует Android 12+; на старших версиях часть эффектов (тени сложных форм) упрощается.
- При включённой «Оптимизации» весь движок тем отключается.
